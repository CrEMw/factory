# Changelog

All notable changes to this project are documented in this file.

The format is based on Keep a Changelog 1.1.0, and this project adheres to Semantic Versioning 2.0.0.

## [Unreleased]

### Added

- Initial public release of the ticket hub engine under the Apache License 2.0.
- `services/hub`: the hub service in Rust on Postgres: tickets and their link graph, people, components, plan
  scopes, document repositories, and an agent mailbox.
- Database migrations embedded in `hub` and applied with `hub migrate`; `HUB_MIGRATIONS=baseline` selects the
  single-file baseline in `services/hub/baseline` (see `docs/migrations.md`).
- Seed import from `HUB_SEED_DIR`, with a neutral example in `examples/seed`.
- `hub-web`: the SvelteKit web UI with Better Auth login, an OAuth provider and an MCP endpoint, in English and
  Russian.
- `apphost/apphost.mts`: an Aspire AppHost for local runs and the source of the Helm chart.
- `deploy/chart`: a Helm chart generated by `tools/chart.sh` from the AppHost and `deploy/overlay`, with neutral
  defaults in `deploy/overlay/values.yaml`.
- `tools/check.sh`: one entry point for all checks.
